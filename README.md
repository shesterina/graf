# Graffics Landing

Простой лендинг на Gulp с поддержкой SCSS и JavaScript.

## Установка

1. Установите зависимости:
```bash
npm install
```

## Разработка

Запустите проект в режиме разработки с автоматической перезагрузкой:
```bash
npm run dev
```

Проект будет доступен по адресу: http://localhost:3000

## Сборка

Для создания production версии:
```bash
npm run build
```

Собранные файлы будут находиться в папке `dist/`.

## Структура проекта

```
graffics/
├── src/              # Исходные файлы
│   ├── index.html   # Главная страница
│   ├── scss/        # SCSS файлы
│   │   └── main.scss
│   ├── js/          # JavaScript файлы
│   │   └── main.js
│   └── images/      # Изображения
├── dist/            # Собранные файлы (создается автоматически)
├── gulpfile.js      # Конфигурация Gulp
└── package.json     # Зависимости проекта
```

## Возможности

- ✅ Компиляция SCSS в CSS
- ✅ Обработка JavaScript
- ✅ Автоматическая перезагрузка страницы (BrowserSync)
- ✅ Source maps для отладки
- ✅ Минификация для production
- ✅ Автопрефиксер для CSS
